# Video Assets

This directory contains video files generated by Manim scenes.

- `svm_margin_scene.mp4`
- `support_vectors_scene.mp4`
- `kernel_trick_scene.mp4`

These videos can be rendered with the following commands:

```
manim -pql manim_scenes/svm_margin_scene.py SVMMarginScene
manim -pql manim_scenes/support_vectors_scene.py SupportVectorsScene
manim -pql manim_scenes/kernel_trick_scene.py KernelTrickScene
```
